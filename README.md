- JavaScript

## 📌 Sobre o projeto

Este projeto foi desenvolvido para centralizar minhas principais informações profissionais e acadêmicas, apresentando:

- Sobre mim
- Formação acadêmica
- Habilidades técnicas
- Projetos
- Experiências
- Formas de contato
- Links para GitHub e LinkedIn

O site possui uma interface responsiva e adaptada para diferentes tamanhos de tela.
